Problem & Solving

CODE LEVEL Trouble Shooting

🔴 1. Git Pages Asset 404
Base URL 경로 불일치로 리소스 로드 실패
// Before: `${baseUrl}${cleanPath}`
🟢 Solution
// After: path.startsWith('/') ? path.slice(1) : path
순수 상대 경로로 변환하여 해결
🔴 2. CSS Import Order
컴포넌트 로드 후 스타일 적용 실패
const Comp = () => {...}
import './Comp.css'; // ❌
🟢 Solution
import './Comp.css'; // ✅
const Comp = () => {...}
Import Hoisting으로 우선순위 확보
🔴 3. Redux Infinite Render
filter()가 매번 새 배열을 반환
useSelector(state => state.items.filter(...))
🟢 Solution
createSelector(items, filters, (i, f) => ... )
Reselect 메모이제이션으로 참조 유지
🔴 4. Vite HMR Frozen
Windows 환경 파일 감시 충돌
// No Config (Default)
🟢 Solution
server: { hmr: { overlay: false }, watch: {...} }
Config 명시적 지정으로 안정화

Outcomes & Growth

프로젝트를 통해 얻은 것

⚛️ React Ecosystem
- Hooks: 의존성 배열 원리 및 클로저 문제 해결
- Custom Hook: 로직 재사용성 및 구조화
- Performance: memo, usageMemo 적절한 사용
🏗 State Architecture
- Redux vs Local: 전역/지역 상태의 명확한 구분
- Selector Pattern: 상태 조회 최적화
- Slice Design: 도메인별 상태 분리
🎨 Styling Philosophy
- CSS Variables: 동적 테마 유연성 확보
- Modern Layout: Grid/Flexbox 반응형 설계
- Zero Runtime: 순수 CSS로 오버헤드 최소화
🛣 SPA Strategy
- URL Sync: URL ↔ UI 상태 동기화
- History: 브라우저 네비게이션 완벽 지원
- Deep Linking: 직접 접근 가능한 경로 설계
